# Forge Gym - Elite Fitness Club

A highly interactive, cinematic fitness experience built with React. This project abandons the traditional layout in favor of a scroll-controlled storytelling approach.

## Key Features
- **Scroll-Controlled Video:** Uses an advanced `<canvas>` frame-by-frame rendering engine perfectly synced to scroll progress.
- **Cinematic Pinned Sections:** Sections like "The Body" pin to the screen while scrolling triggers image crossfades and kinetic typography.
- **GSAP Animations:** Heavy use of GSAP ScrollTrigger for parallax, text reveals, and complex timeline scrubbing.
- **Custom Smooth Scrolling:** Implemented using Lenis for butter-smooth parallax and scroll-scrubbing interactions.

## Tech Stack
- React + Vite
- GSAP (ScrollTrigger)
- Lenis (Smooth Scrolling)
- Framer Motion
- TailwindCSS

## Setup
```bash
npm install
npm run dev
```
