# Nuance - High-End Salon & Spa

An elegant, minimalist React application designed for luxury hair salons, spas, and boutique beauty studios.

## Key Features
- **Minimalist Aesthetics:** Focuses on typography, negative space, and a refined beige/monochrome color palette.
- **Micro-Interactions:** Subtle hover effects, image reveals, and smooth transitions that elevate the user experience.
- **Service Menus & Booking:** Structured layouts for showcasing complex service menus and booking calls-to-action.
- **Custom Scroll Behavior:** Integrated smooth scrolling for a premium, app-like feel on the web.

## Tech Stack
- React + Vite
- TailwindCSS 
- Framer Motion
- Lenis Smooth Scroll

## Setup
```bash
npm install
npm run dev
```
